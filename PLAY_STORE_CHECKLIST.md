# Google Play release checklist

- Set a unique application ID before first production release if desired.
- Create a signed Android App Bundle (AAB) with a release keystore.
- Keep the keystore and passwords outside GitHub.
- Complete the Play Console Data safety form accurately.
- Provide a public privacy-policy URL if required by the Play Console configuration.
- Add app icon, feature graphic, screenshots and store description.
- Complete content rating and target-audience declarations.
- Test the release build on physical Android devices.
- Verify crash-free startup, gameplay, restart, persistence and back navigation.
- Review Google Play policies before submission.
